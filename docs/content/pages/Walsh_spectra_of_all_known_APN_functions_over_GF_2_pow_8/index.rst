Overview
--------

The tables below contain the Walsh spectra for all
:ref:`known instances of APN functions over GF(2^8) <known_instances_of_apn_functions_over_gf_2_pow_8>`.
All of these `8192` functions have one of the following three Walsh spectra.

Gold-Like Spectrum
------------------

This is the same Walsh spectrum as the Gold functions:

`\{-32^{2380}, -16^{20400}, 0^{16320}, 16^{23120}, 32^{3060}\}`.

Walsh Spectrum of Type 1
------------------------

`\{-64^{6}, -32^{2240}, -16^{20880}, 0^{15600}, 16^{23664}, 32^{2880}, 64^{10}\}`.

Walsh Spectrum of Type 2
------------------------

`\{-64^{12}, -32^{2100}, -16^{21360}, 0^{14880}, 16^{24208}, 32^{2700}, 64^{20}\}`.

There are `12` functions with a Walsh spectrum of type 2, `487` functions with
a Walsh spectrum of type 1, and `7693` functions with a Gold-like Walsh
spectrum.
