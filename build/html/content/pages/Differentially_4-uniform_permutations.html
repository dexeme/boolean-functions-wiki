Differentially 4-uniform permutations¶

Function Conditions References
\(x^{2^i+1}\) \(gcd(i, n) = 2\), \(n = 2t\) and \(t\) is odd [Gol68], [Nyb94]
\(x^{2^{2i}-2^i+1}\) \(gcd(i, n) = 2\), \(n = 2t\) and \(t\) is odd [Kas71]
\(x^{2^n-2}\) \(n = 2t\) (inverse) [Nyb94], [LW90]
\(x^{2^{2t}+2^t+1}\) \(n = 4t\) and \(t\) is odd [BL09]
\(\alpha x^{2^s+1} + \alpha^{2^t} x^{2^{-t+2^{t+s}}}\) \(n = 3t\),\(\)
\(t/2\) is odd,
\(gcd(n, s) = 2\),\(\)
\(3|t + s\) and \(\alpha\) is a primitive element in \(\mathbb{F}_{2^n}\)		 [TQTL12]
\(x^{-1} + Tr_1^n(x + (x^{-1} + 1)^{-1})\) \(n = 2t\) is even [TQTL12]
\(x^{-1} + Tr_1^n(x^{-3(2^k+1)} + (x^{-1} + 1)^{3(2^k+1)})\) \(n = 2t\) and \(2 \leq k \leq t - 1\) [TQTL12]
\(L_u(F^{-1}(x))|_{H_u}\) \(n = 2t\), \(F(x)\) is a quadratic APN permutation on \(\mathbb{F}_{2^{n+1}}\),\(\)
\(u \in \mathbb{F}_{2^{n+1}}^*\),
\(L_u(x) = F(x) + F(x+u) + F(u)\),
\(H_u = \{L_u(x) | x \in \mathbb{F}_{2^{n+1}}\}\)		 [LW14]
\(\sum_{i=0}^{2^n-3} x^i\) \(n = 2t\), \(t\) is odd [YMY13]
\(x^{-1} + t(x^{2^s} + x)^{2^{sn}-1}\) \(s\) is even, \(t \in \mathbb{F}_{2^s}^*\),
or
\(s\), \(n\) are odd, \(t \in \mathbb{F}_{2^s}^*\)		 [ZHS14]
\(x^{2^k+1} + t(x^{2^s} + x)^{2^{sn}-1}\) \(n\), \(s\) are odd, \(t \in \mathbb{F}_{2^s}^*\), \(gcd(k, sn) = 1\) [TQTL12]
\((x, x_n) \mapsto ((1 + x_n)x^{-1} + x_n \alpha x^{-1}, f(x, x_n))\) \(n\) is even
\(x\), \(\alpha \in \mathbb{F}_{2^{n-1}}\),\(\)
\(x_n \in \mathbb{F}_2\),\(\)
\(Tr_{n-1}(\alpha) = Tr_{n-1}(1/\alpha) = 1\),
\(f(x, f(x, x_n)\) is \((n, 1)\)-function		 [CTTL14]

[BL09, CTTL14, Gol68, Kas71, LW90, LW14, Nyb94, TQTL12, YMY13, ZHS14]
